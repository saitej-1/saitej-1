## Projects

### [FoodMed Check](https://github.com/saitej-1/foodmed-check): explainable drug–food interaction prediction
A full-stack platform that predicts whether a drug and a food compound are likely to interact.
- Molecular features engineered with RDKit, an XGBoost classifier, and SHAP to show which features drive each prediction
- ML inference served through a FastAPI backend, a Next.js frontend and a PostgreSQL database

`Python` `XGBoost` `RDKit` `SHAP` `FastAPI` `Next.js` `PostgreSQL`

### [Aegis AI](https://github.com/saitej-1/drug-food-intraction-platfrom): food and drug interaction profiler
A browser app that predicts whether a food and a medicine are likely to interact (safe, moderate or severe).
- Neural network written from scratch in JavaScript (forward pass, backpropagation, training loop, no ML library), trained live in the browser
- Dataset of 54 foods and 49 drugs (2,646 pairs) encoded as pharmacological features
- SMILES parser and a 3D ball-and-stick molecule viewer built with Three.js

`React` `Vite` `Three.js` `JavaScript` `Python`
